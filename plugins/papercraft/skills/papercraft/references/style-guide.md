# 페이퍼크래프트 학습지 스타일 가이드

레퍼런스(말랑 큐브 고양이, 3D 토끼, 치비 인형, 큐브 고양이, 너구리·여우·펭귄·코알라 로우폴리)에서 뽑은 규칙이다. 생성기는 이 규칙을 코드로 지킨다. 새 동물을 설계할 때는 이 규칙 안에서 값만 고른다.

## 1. 모양: 상자 두 개로 만드는 "큰 머리 아기"
- 머리 직육면체(기본 52×44×40mm)가 몸통(38×30×30mm)보다 훨씬 크다. 머리:몸 높이 ≈ 3:2. 치비 비율.
- 귀·꼬리는 따로 오린 납작 부품. 풀칠 날개를 접어 머리 윗면·몸통 뒷면의 **점선 자리**에 붙인다.
- 손·발은 오리지 않고 몸통 앞면에 그린다(아이 손으로 오리기 쉬움).
- 전개도는 가로 띠: 왼쪽옆·앞·오른쪽옆·뒤가 한 줄, 윗면·아랫면은 앞면 위아래. 모든 면이 바깥에서 바로 서 보인다.

## 2. 선
- 자르는 선: 진한 갈색 실선(#3B2E2E, 0.5mm). 접는 선: 회갈색 점선. 풀칠 날개: 아이보리 사다리꼴 + "풀".
- 붙이는 자리: 흐린 점선 네모 + 작은 글씨(귀, 몸통 위에 붙여요).
- 범례(자르는 선/접는 선/풀칠하는 날개/붙이는 자리)를 꼭 넣는다.

## 3. 얼굴
- 눈: 크고 까만 타원 + 흰 하이라이트 두 개(큰 것 오른쪽 위, 작은 것 왼쪽 아래). 미간이 넓다(얼굴 폭의 44%).
- 볼: 분홍 타원 + 흰 빗금 세 개(///).
- 입: ω 또는 작은 웃음. 코: 분홍 하트형(고양이·토끼), 까만 단추(곰·여우·너구리), 부리(새).
- 얼굴은 앞면 아래쪽 절반에 모이고 위쪽은 이마 무늬·리본 자리.

## 4. 색과 무늬
- 파스텔 단색 면, 그라데이션·그림자 없음. 밝은 색(light)은 배·주둥이·뺨에만.
- 결 무늬는 끝이 뾰족해지는 줄(이마 3줄, 옆면은 뒤쪽 모서리에서 앞으로).
- 장식은 하나만: 리본·꽃·목도리·하트·씨앗.

## 5. 학습지 한 장 구성(A4 세로)
1. 머리띠: 둥근 제목 상자(Jua), 한 줄 부제, 이름 줄, 범례.
2. 가운데: 전개도. 빈칸에 하트·반짝이 2~4개.
3. 아래 세 칸: ✂ 만드는 순서(5단계) · 완성 모습(같은 그림으로 그린 사선 투상도) · 탐구 활동.
   - math: 직육면체의 면·모서리·꼭짓점 수, 마주 보는 면(초등 5학년 수학 '직육면체' 단원과 연결).
   - story: 내 친구 소개(이름·좋아하는 것·잘하는 것·하고 싶은 말).
4. 맨 아래: 완성 크기와 "실제 크기(100%) 인쇄" 안내.

## 6. 말투
- 아이에게 말하는 짧은 존댓말: "굵은 실선을 따라 오려요."
- 제목은 "아기 OO 만들기"처럼 12자 안팎.

## 7. 다면체(로우폴리) 스타일 — 코알라·펭귄·여우 레퍼런스
- 머리는 고리 6단 × 8각의 다면체 공. 앞 뚜껑(팔각형) 한 장에 얼굴 전체를 그리고, 전개도에서 얼굴이 섬 가운데에 똑바로 오게 펼친다.
- 몸통은 서양배 모양 5단 다면체. 다리·앞발·꼬리·귀는 몸통/머리의 **한 면에서 돋아나는 조각**이라 붙이는 면이 정확히 맞닿는다(붙일 자리는 점선 + 이름).
- 면마다 빛 방향(왼쪽 위 앞)에 따른 밝기를 살짝 입혀 종이 위에서도 입체감이 보이게 한다.
- 무늬는 부위별 정면·옆·위 투영 그림을 면마다 잘라 붙인다(이음선에서 무늬가 이어진다).
- 이음선은 같은 번호끼리 붙인다. 날개에도 번호, 짝 모서리 안쪽에도 같은 번호.
- 회색 점선 = 바깥으로 접기(산), 파란 일점쇄선 = 안으로 접기(골).
- A4 2쪽: 1쪽 머리(+탐구 칸), 2쪽 몸통·다리·꼬리·귀. 완성 높이 약 11cm.
