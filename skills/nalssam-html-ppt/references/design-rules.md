# 장을 짤 때 지키는 기준

장을 만들기 전에 읽고, 점검할 때 다시 본다. 용어와 기준은 Design in words(designinwords.onpod.ai)의 슬라이드용 용어를 날쌤 덱에 맞게 다시 정리한 것이다. 괄호 안은 그 사이트가 밝힌 근거다.

## 구성

| 기준 | 값 | 어기면 |
|---|---|---|
| 한 장 한 메시지 | 제목 = 결론 한 문장, 근거는 숫자 하나 + 그림 하나 | 결론이 셋이면 세 장으로 나눈다 |
| 초점 | 한 장에 하나. 가장 크게, 키컬러로, 둘레를 비운다 | 강조가 셋을 넘으면 아무것도 강조되지 않는다 |
| 위계 | 크기 → 굵기 → 여백 → 색 순서로 만든다 | 색부터 바꾸면 알록달록해지기만 한다 |
| 정렬 | 한 장에 시작선 하나. 긴 글은 왼쪽, 가운데 정렬은 짧은 제목에만 | 시작선이 둘이면 시선이 끊긴다 |
| 근접성 | 묶음 사이 간격 = 묶음 안 간격의 3배 | 상자부터 그리면 간격 차이가 묻힌다 |
| 시선 흐름 | 글이 적은 장은 Z자: 왼쪽 위에서 시작해 오른쪽 아래에서 끝난다 | 핵심어를 줄 끝에 두면 읽히지 않는다 |

## 글자와 간격

| 기준 | 값 |
|---|---|
| 간격 | 8의 배수만. 글줄 사이 16, 묶음 사이 32, 바깥 여백 48 이상. 단계는 5~7개 |
| 타입 스케일 | 본문에서 제목까지 1.2~1.5배씩. 1.1 이하는 차이가 안 보인다 |
| 행간 | 한글 본문 1.5~1.6. 1.3 이하면 줄을 놓친다 (WCAG 1.4.12) |
| 자간 | 큰 제목만 −2% 안팎. 본문은 건드리지 않고, 한글 라벨에 0.1em 넘는 자간은 쓰지 않는다 |
| 대비 | 본문 4.5:1 이상, 큰 글자(약 24px 이상) 3:1 이상 (WCAG 1.4.3) |
| 라운드 | 한 덱에 둥글기 값은 세 가지까지. 안쪽 요소는 바깥보다 덜 둥글게 |

## 색

- **키컬러 하나**: 키커·번호·강조 막대·민트 띠에만 쓴다. 제목과 배경까지 칠하면 강조가 사라진다.
- **60-30-10**: 바탕 60, 보조 30, 강조 10. 숫자를 맞추기보다 강조색을 아주 조금만 쓴다(경험칙).
- **포인트 색(코랄)**: 마지막 칸, 원칙 한 줄처럼 한 장에 한 곳.
- **그라데이션**: 이유 없는 보라·분홍 그라데이션은 쓰지 않는다. 쓴다면 한 색 안에서 밝기만.
- **색만으로 뜻을 전하지 않는다**: 차트 값은 숫자로도 적고, 짚은 곳은 테두리와 글로도 알린다.

## 그림과 차트

| 상황 | 방법 | 피할 것 |
|---|---|---|
| 순위·비교 | 큰 순서로 정렬한 가로 막대, 말할 막대 하나만 키컬러 | 조각 5개 넘는 원그래프, 막대마다 다른 색 |
| 숫자 여러 개 | 셋만 골라 큰 숫자 + 한 줄 설명 | 숫자 열 개를 모두 그림으로 |
| 화면 캡처 | 한 곳만 테두리로 짚고 나머지는 어둡게, 옆에 한 줄 | 한 장에 콜아웃 4개 이상, 설명 없는 빨간 동그라미 |
| 사진 위 글자 | 글자 쪽에만 아래에서 위로 옅어지는 어두운 스크림 | 사진 전체를 어둡게, 글자 그림자만 진하게 |
| 사진 + 글 | 1:2 로 나누고 주인공 쪽을 넓게 | 반반 분할 |
| 전면 사진 | 선명하고 큰 사진만 | 작은 사진을 늘려 깨지게 |
| 아이콘 | 한 덱에 한 세트. 같은 굵기·같은 색 | 선 아이콘과 면 아이콘 섞기 |

## 점검할 때 묻는 것

1. 1초만 보고 눈을 돌렸을 때 기억나는 것이 하나인가.
2. 제목만 이어 읽어도 발표의 줄거리가 되는가.
3. 내용을 빼기 전에 여백부터 늘려 보았는가.
4. 이 장의 포인트 색은 한 곳뿐인가.
5. 숫자와 인용에 출처가 있는가, 예시에 `(가상)` 이 붙었는가.
