# nalssam-html-ppt · 날쌤 스타일 HTML PPT

`nalssam-pptx` 의 짝이다. 같은 얼굴(색·글꼴·결론 제목·대본)을 **브라우저로 여는 HTML 파일 하나**로 만든다. 파워포인트 파일이 필요하면 `nalssam-pptx` 를 쓰고, 링크로 나누거나 움직임이 필요하면 이 스킬을 쓴다.

새로 만드는 것은 **내용**뿐이다. 엔진(CSS·JS)과 장표 틀은 `assets/starter.html` 을 복사해서 그대로 쓴다. 기억으로 다시 짜지 않는다.

## 1. 시작 전 확인

요청에 이미 있는 것은 다시 묻지 않는다. 모자란 것만 한 번에 묻는다.

1. **내용**: 넣을 글이나 자료(지도안·안내문·PDF·메모). 주제 한 줄만 받았으면 만들지 말고 내용을 먼저 받는다. "알아서 써 줘"라고 한 때에만 초안을 쓰고, 초안이라고 한 줄로 알린다.
2. **행사**: 이름·날짜·대상·총 시간·본문 장수. 표지와 감사 장은 장수에 넣지 않고 따로 더한다.
3. **대본**: 녹화 낭독형(분당 300~350자) / 라이브 요점형(분당 약 100자 + `[시연]`·`[참여]` 큐).
4. **테마**: `nalssam`(기본) / `chalk`(칠판) / `navy`. 다른 브랜드 톤을 원하면 `references/brand-themes.md` 를 따른다.

## 2. 스타일 한눈에

- **분위기**: 웜 오프화이트 바탕 위 네이비 글씨, 틸 포인트, 코랄 한 방울. 여백이 넉넉하다. 카드는 흰 바탕에 얇은 베이지 테두리의 **납작한 둥근 상자(그림자 없음)**.
- **글꼴**: Pretendard 하나. 제목 800, 본문 400~700.
- **문장**: 제목 = 결론 한 문장(30자 안팎, 두 줄까지). 키커 = `01 섹션명`. 한 장 한 메시지, 근거 2~5개. 아래 **민트 띠**로 한 줄 결론. 같은 유형을 3장 연속으로 쓰지 않는다.
- **바닥글**: `행사명 | nalssam 박준호 | 날짜` + 오른쪽 `NN / 총장수`. 자동으로 붙는다(표지·전면·감사 장 제외).
- **말투**: 화면 글은 짧은 `~해요`, 대본은 구어체 존댓말.
- **지어내지 않는다**: 숫자·연도·인용은 확인한 것만. 예시는 `(가상)` 이라고 적는다. 학생 실명·얼굴·개인정보는 넣지 않는다.

토큰(색·간격·이징)은 `starter.html` 맨 위 `:root` 에 있다. 값은 `nalssam-pptx` §4 와 같다.

| 이름 | 값 | 쓰임 |
|---|---|---|
| `--bg` / `--ink` / `--sub` | `#FBFAF6` / `#132C3D` / `#586875` | 바탕 / 제목·본문 / 부제·설명·바닥글 |
| `--key` / `--key-soft` | `#18766B` / `#E3F0EC` | 키커·번호·강조 막대 / 민트 띠·칩 바탕 |
| `--point` | `#D9734E` | 마지막 칸·원칙 한 줄. 화면에 아주 조금만 |
| `--line` / `--card` / `--paper` / `--zebra` | `#E4DFD3` / `#FFFFFF` / `#F3F0E8` / `#F5F2EA` | 카드 테두리 / 카드 / 그림 자리 / 표 줄무늬 |

## 3. 작업 순서

1. **확인**(§1).
2. **장 목록**: 번호 · 제목(결론 문장) · 장표 유형(§4) · 장별 분. 기본 골격은 `표지 → 오늘의 질문 → (간지 → 본문: 개념 → 사례 → 시연 → 실습)× → 요약 → 내일 시작할 한 가지 → 출처 → 감사 + QR`. 길면 목록을 먼저 보여 주고 확인받는다.
3. **그림 목록**: 그림이 들어갈 장마다 `번호_이름`(예: `07_교실`)으로 필요한 그림을 알려 준다. 받기 전에는 그림 자리(`.ph`)를 둔다. 수업 사진·작품·화면 캡처는 만들지 않고 받는다.
4. **조립**: `starter.html` 을 작업 폴더에 복사 → `#stage` 의 `data-event`·`data-author`·`data-date` 를 바꾼다 → 견본 장(`<section class="slide">`)을 복사해 글자를 바꾼다. 안 쓰는 견본 장은 지운다. 장마다 `data-title`(겹치면 안 됨)과 `<aside class="notes">` 대본을 쓴다.
5. **점검**(§7): `node scripts/check.js 덱.html shots` → 캡처를 **전부** 눈으로 본다.
6. **글꼴 넣기**(인터넷 없는 곳에서 쓸 때): `python3 scripts/inline_font.py 덱.html 완성.html`.
7. **전달**: 파일과 함께 장수 · 총 시간 · `(가상)` 표시한 예시 · 확인하지 못한 사실을 한두 문장으로 알린다.

## 4. 장표 유형 (스타터의 견본 장)

| # | data-title | 클래스 | 쓰임 |
|---|---|---|---|
| 1 | 표지 | `.cover` | 큰 제목 두 줄 + 한 줄 문구 + 소속, 오른쪽 그림 |
| 2 | 오늘의 질문 | `.g3.cards3` | 3열 카드. 소개·질문·사례 |
| 3 | 간지 · 구성 | `.divider` | 화면 밖으로 나가는 큰 번호 + 파트 제목. `data-theme="navy"` |
| 4 | 한 장 한 메시지 | `.msg` | 결론 제목 + 큰 숫자 하나 + 그림 하나 + 민트 띠 |
| 5 | 정렬한 막대 차트 | `.bars` | 큰 순서로 정렬, 말할 막대(`.hl`) 하나만 키컬러 |
| 6 | 큰 숫자 셋 | `.g3.stats` | 숫자 셋 + 한 줄 설명. 숫자는 올라가며 나타난다 |
| 7 | 사진과 글 | `.split` | 1:2 분할(`.rev` 는 2:1) |
| 8 | 번호 목록 | `.nlist` | 큰 번호 + 굵은 한 줄 + 작은 설명. 첫 줄 `.hl` |
| 9 | 타임라인 | `.tl` | 4칸, 마지막 칸만 포인트 색 |
| 10 | 비교표 | `.tbl` | 핵심 열(`.k`)만 진하게 |
| 11 | 단계 카드 | `.g4.steps` | 번호 원 + 제목 + 설명, 최대 4칸 |
| 12 | 인용 | `.quote` | 왼쪽 그림 + 큰 인용(3줄 수동 줄바꿈) + 칩 3개 |
| 13 | 전후 대비 | `.vs` | 좌우 색이 갈리는 전·후 |
| 14 | 콜아웃 | `.callout` | 캡처 한 곳만 테두리로 짚고 나머지는 어둡게 |
| 15 | 전면 이미지 | `.full` | 끝까지 찬 그림 + 아래 스크림 + 흰 제목 |
| 16 | 칠판 테마 | `data-theme="chalk"` | 한 장만 테마 바꾸기 |
| 17 | 참고문헌 | `.refs` | 출처 모음 |
| 18 | 감사 | `.thanks` | 감사 인사 + QR 카드 |

한 장의 뼈대:

```html
<section class="slide" data-title="겹치지 않는 장 이름">
  <div class="kicker">01 섹션명</div>
  <h2 class="title">결론 한 문장</h2>
  <p class="lead">부제 한 줄(선택)</p>
  <div class="body"> …부품… <div class="band" data-step="1">한 줄 <b>결론</b></div></div>
  <aside class="notes">4장 · 2분
구어체 대본…</aside>
</section>
```

- 강조: `<em>` = 키컬러, `.pt` = 포인트 색, `<b>` = 굵게. 한 장에 두세 곳만.
- 그림: `<img class="shot zoom" src="data:image/jpeg;base64,…">` (`.zoom` 은 누르면 크게). 긴 변 1400px, JPEG 품질 80 안팎으로 줄여 파일 안에 넣는다.
- 새 배치가 꼭 필요하면 그 장에만 인라인 `style` 로 조금 고친다. 간격은 `--s1`~`--s6`(8의 배수)만 쓴다.

## 5. 움직임

엔진에 이미 들어 있다. 쓰는 법만 지킨다. 자세한 근거는 `references/motion.md`.

- **단계 등장**: `data-step="1"`, `"2"`… → 를 누를 때마다 차례로 나온다. 같은 번호는 같이. 한 장에 4단계 안팎. `data-fx="fade"`(제자리에서), `"pop"`(톡).
- **차례 등장**: 묶음에 `.stag` 를 붙이면 자식이 60ms 간격으로 나온다. 순서가 있는 것에만.
- **숫자 올라가기**: `<span data-count="12400">0</span>`, 소수는 `data-dec="1"`.
- **글자 등장**: `.kin` — 표지·간지·감사 제목 한 줄에만. 1초 안에 끝난다.
- **선 자라기**: `.grow`.
- **장 전환**: 기본은 페이드 0.3초 하나. 간지처럼 크게 바뀌는 장에만 `data-tr="wipe|circle|slice"`.
- 화면에 `움직임 줄이기`가 켜져 있으면 모두 꺼진다. 5초 넘게 도는 반복 움직임은 넣지 않는다.

## 6. 대본 규칙

- 장마다 `<aside class="notes">` 에 쓴다. 발표 중 `N` 키로 아래에 뜬다.
- 첫 줄은 `7장 · 3분 · 10:17~10:20`(시각을 모르면 `7장 · 3분`), 다음 줄부터 구어체 본문.
- 길이는 §1 의 대본 유형을 따르고, 장별 분을 더해 행사 시간과 맞는지 검산한다.
- 한 장의 대본은 그 장의 제목(결론)을 말로 한 번 더 닫는다. 첫 장에 인사, 마지막 장에 마무리 인사와 QR 안내.

## 7. 점검과 전달

```bash
node scripts/check.js 덱.html shots            # 1600×900, 장마다 마지막 단계까지 펼쳐 캡처
node scripts/check.js 덱.html shots-m --mobile # 휴대폰 세로 화면
```

- `문제 없음`이 나와야 한다. `주의`(화면 밖·바닥글과 겹침·잘림·제목 3줄·이름표 제목·대본 없음·`data-title` 겹침)는 하나씩 고친다. 넘치면 글자를 줄이지 말고 문장을 줄이거나 장을 나눈다.
- 캡처를 모아 전부 본다. 볼 것: 제목이 결론 문장인가, 강조가 한 장에 셋을 넘지 않는가, 포인트 색이 넓게 쓰이지 않았는가, 같은 유형이 3장 연속인가, 아래가 텅 비지 않았는가, 그림 자리가 남아 있지 않은가.
- 움직임과 전환은 정지 화면에 안 보이니 사용자에게 직접 열어 확인해 달라고 한 줄 덧붙인다.
- **PDF**: 브라우저에서 `P` → 대상 "PDF로 저장", 여백 없음, 배경 그래픽 켜기. 한 장이 한 쪽으로, 모든 단계가 보인 상태로 나온다.
- **키**: `→`·`Space` 다음 / `←` 이전 / `PgDn`·`PgUp` 장 단위 / 숫자+`Enter` 이동 / `G` 목록 / `N` 대본 / `F` 전체 화면 / `P` 인쇄 / `?` 도움말. 휴대폰은 좌우로 민다.

## 8. 테마

- `#stage` 의 `data-theme` 이 덱 전체, `<section>` 의 `data-theme` 이 그 장만 바꾼다.
- 간지·강조 장은 `navy`, 질문·활동 장은 `chalk` 이 어울린다. 한 덱에서 본문 테마는 하나로 통일한다.
- 포인트 색만 바꾸려면 `:root` 의 `--key`·`--key-soft` 두 값을 바꾼다. 흰 글자가 올라가는 색이라 본문 대비 4.5:1 을 넘는 진한 색으로 고른다.
- 한국 서비스의 디자인 톤을 빌리려면 `references/brand-themes.md`.

## 9. 함정

1. `<section>` 안의 태그 짝이 안 맞으면 뒤 장이 통째로 사라진다 → `check.js` 의 장수가 목록과 같은지 본다.
2. 그림 자리(`.ph`)를 그대로 둔 채 전달하지 않는다. 남겼으면 어느 장인지 알린다.
3. Pretendard 는 인터넷에서 받아 온다. 인터넷이 없는 곳에서는 기본 글꼴로 바뀌니 `inline_font.py` 를 돌린 파일을 준다. 글자를 고친 뒤에는 다시 돌린다.
4. 차트 막대는 `--v`(가장 큰 값을 100 으로 본 비율)로 길이를 정한다. 값 자체는 막대 끝 숫자로 적는다.
5. 이 엔진에는 실시간 투표·채팅·타이머·음악이 없다. 그런 참여 기능이 필요한 연수는 그 기능이 들어 있는 다른 덱 엔진을 쓴다.

## 10. 참고 파일

- `assets/starter.html` — 엔진 + 견본 18장. 원본은 고치지 않고 복사해서 쓴다.
- `scripts/check.js` — 캡처와 넘침·대본·제목 검사(Playwright).
- `scripts/inline_font.py` — 쓰인 글자만 담은 Pretendard 를 파일 안에 넣는다.
- `references/design-rules.md` — 장을 짤 때 지키는 수치 기준과 피할 것.
- `references/motion.md` — 이징·전환·시차 값과 그 근거.
- `references/brand-themes.md` — 다른 브랜드 톤을 입히는 법.
