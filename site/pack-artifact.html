한 줄로 설치하기


      

      
Claude Code(~/.claude/skills)와 Codex(~/.agents/skills)에 아래 표의 "팩에 포함" 스킬을 넣습니다. 설치 뒤 Claude Code 나 Codex 를 새로 엽니다.

    

  


  

    
들어 있는 스킬

    

      
날쌤 HTML PPTnalssam-html-ppt

        
팩에 포함브라우저로 여는 발표 덱을 파일 하나로 만듭니다. 결론 문장 제목, 장마다 대본, 넘기기·단계 등장·PDF 저장.

        

      
날쌤 PPTXnalssam-pptx

        
팩에 포함파워포인트 파일로 연수 원고 덱을 만듭니다. 글꼴이 파일에 들어가고 메모란에 대본이 붙습니다. 공개판이라 제안서 모드는 빠져 있습니다.

        

      
PDFpdf

        
팩에 포함PDF 읽기·합치기·나누기·양식 채우기. Anthropic 이 공개한 스킬입니다(Apache 2.0). Claude 앱에는 이미 들어 있어 Codex 와 Claude Code 에서 쓸 때 필요합니다.

        

      
HWPX 한글 문서hwpx

        
원본에서 설치한글(.hwp·.hwpx) 문서 만들기·변환·양식 채우기. jkf87 님이 만든 스킬이라 팩에 복사하지 않고 원본 저장소에서 바로 받습니다. Node 가 필요합니다.
          npx skills add jkf87/hwpx-skill -g -a claude-code codex -y

        원본 열기

      
Docs 문서docs

        
설치 불필요함께 고치는 문서. Claude 앱에 기본으로 들어 있는 기능이라 따로 받을 것이 없습니다. Claude 앱에서 "문서로 만들어 줘"라고 하면 됩니다.
