저장하기

스킬 ZIP 받기

고른 스타일이 들어간 스킬 폴더를 ZIP 하나로 받습니다. 저장할지 묻는 창이 한 번 뜹니다.

설정 한 줄

이 한 줄을 복사해 Claude 대화창에 붙여 넣고 "이 설정으로 스킬 저장해 줘"라고 합니다. Claude 가 스킬 ZIP 을 만들어 줍니다.

내 AI 에 붙이기

Claude 앱

  1. 설정 > 기능에서 코드 실행 및 파일 생성을 켭니다.
  2. 사용자 지정 > 스킬에서 + 를 누르고 스킬 만들기 > 스킬 업로드를 고릅니다.
  3. 받은 ZIP 을 그대로 올립니다. 풀지 않습니다.
  4. 새 대화에서 "(으)로 PPT 만들어 줘"라고 합니다.

Claude Code

  1. ZIP 을 풉니다.
  2. 폴더를 ~/.claude/skills// 에 둡니다. 한 프로젝트에서만 쓰려면 .claude/skills/ 아래에 둡니다.
  3. / 로 부르거나 그냥 PPT 를 부탁합니다.

Codex

  1. ZIP 을 풉니다.
  2. 폴더를 ~/.agents/skills// 에 둡니다. 한 저장소에서만 쓰려면 .agents/skills/ 아래에 둡니다.
  3. $ 로 부릅니다. 안 보이면 Codex 를 다시 켭니다.
